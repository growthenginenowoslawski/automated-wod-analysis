# WOD Tracker (web app) — tracking test

The week-1 test for the WOD Tracker app: body tracking on the phone in Safari, same MediaPipe model (0.10.32, pose_landmarker_full) and settings as the open-source desktop tool, saved in the same `pose.json` format so the Python engine analyzes it unchanged.

Static site, no build step. `python3 -m http.server` in this folder to run it locally.
