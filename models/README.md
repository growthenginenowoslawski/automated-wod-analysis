# Models

`pose_landmarker_full.task` is Google's MediaPipe Pose Landmarker (full) model, redistributed unchanged as a
backup download source for networks that block `storage.googleapis.com`. MediaPipe and its models are released
by Google under the Apache License 2.0: https://github.com/google-ai-edge/mediapipe ·
https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker
The primary download remains Google's own URL; `wod setup` only uses this copy if that fails.
